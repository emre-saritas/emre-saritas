## 🔧 What I work on

- **ERP & legacy integrations** – SOAP/XML, REST and SFTP integrations with third-party ERP systems: order, stock, invoice and payment sync
- **Safe data synchronization** – full/delta loads with versioned datasets, so a failed refresh never leaves the system empty or half-updated
- **Resilient file ingestion** – SFTP pipelines with charset fallback, malformed-CSV handling, multipart ordering and protection against destructive refreshes
- **Reliability patterns** – idempotent payment/balance operations; layered retries that separate transport failures (backoff + jitter) from domain-level retries
- **Performance at volume** – batching, chunking, indexing and memory-aware processing; PostgreSQL tuning and JVM OOM fixes
- **Production ownership** – root-cause analysis of timeouts, sync failures, JVM memory pressure and Kubernetes resource issues
